sku-shifter

Move your product catalog between platforms, by file.

Export your products from one platform, convert the file here, and import it into the other. No store logins, no accounts, no per-SKU fees, and your file never leaves this device.

Honest limits

      
Files carry image URLs or file references, never the images themselves. Import your target store while the source store is still live so it can fetch the images. Category systems differ: some targets key categories by numeric IDs that no source file contains, and the conversion report says exactly where that applies. Nothing is dropped silently: every field that could not be carried is listed in the report with the reason.
